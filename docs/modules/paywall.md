# Paywall Manager

Modul sensor dan pemeliharaan paywall in-game untuk operasional rental atau world berbayar.

## Kemampuan

- **Sensor Expire**: Membaca sisa waktu aktif paywall pada tile target.
- **Auto Renew**: Membayar biaya perpanjangan sekitar 2 menit sebelum batas waktu kedaluwarsa tercapai (`AutoRenewPaywall = true`).
- **Auto Buy**: Mengidentifikasi paywall yang dicabut paksa atau habis mendadak dan melakukan pembelian kembali di world (`AutoBuyPaywall = true`).
- **Bypass Safety**: Menjamin bot dapat beroperasi tanpa terhalang atau terkena penalti sistem saat bergerak di sekitar portal/paywall.
