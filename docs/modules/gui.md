# GUI v3 Clean Dark

Antarmuka grafis in-game yang dirender menggunakan API `ImGui` dari BooLua.

## Tampilan

- **Main Panel**: Jendela mengambang di kiri bawah game, dapat dipindahkan.
- **Status Bar**: Menampilkan gems/menit, total gems, durasi runtime, dan status aktif setiap modul.
- **Tab Settings**: Tombol toggle on/off untuk tiap fitur utama tanpa perlu keluar dari game.
- **World Input**: Field teks input nama world dan koordinat tile target.
- **Monitor Status**: Indikator koneksi ke fleet dashboard (hijau/merah).

## Shortcut

| Shortcut | Aksi |
| :--- | :--- |
| **Tombol Start** | Memulai loop PNB utama |
| **Tombol Stop** | Menghentikan bot sementara tanpa keluar dari script |
| **Reset** | Mengembalikan state mesin ke posisi awal IDLE |
